# Star Wars App - Gestion Galactica

## Descripcion del Proyecto
Esta aplicacion Android ha sido desarrollada como parte de las Tareas 2, 3 y 4 del modulo de Programacion Multimedia y Dispositivos Moviles. Permite la gestion completa de personajes de Star Wars y sus planetas de origen utilizando una arquitectura moderna.

## Tecnologias Utilizadas
- Jetpack Compose: Interfaz de usuario declarativa.
- MVVM (Model-View-ViewModel): Separacion de logica de negocio y UI.
- Hilt: Inyeccion de dependencias.
- Room Database: Persistencia de datos local con relaciones maestro-detalle.
- Navigation Compose: Gestion de navegacion global con Drawer.

## Guia de Instalacion
1. Descarga el archivo StarWars_ToroFrancisco.apk.
2. En tu dispositivo Android, activa la instalacion desde "Fuentes Desconocidas".
3. Abre el archivo APK e instalalo.
4. Concede el permiso de Notificaciones cuando la aplicacion lo solicite para recibir confirmaciones de alta.

## Manual de Usuario
1. Inicio: Al abrir la aplicacion, veras la lista de personajes ya registrados.
2. Navegacion: Desliza el dedo desde el borde izquierdo o pulsa el icono de menu para moverte entre el listado de Personajes y el de Planetas.
3. Anadir: Pulsa el boton flotante (+) para registrar un nuevo elemento. Es obligatorio rellenar los campos principales.
4. Borrar: Manten pulsado cualquier elemento de la lista para eliminarlo tras confirmar el aviso.
5. Sobre nosotros: Accede al menu de opciones arriba a la derecha para conocer al desarrollador.
